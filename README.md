# Rock-paper-scissors-game
A classic Rock, Paper, Scissors game programmed in Python. Play against the computer by entering your choice, while the system makes a selection to determine the result (win, lose, or tie) based on logical conditions. A simple, fun project to practice basic programming and user interaction.
## 📝 Note

The **rock, paper, and scissors** in the game are named using **Arabic transliteration**.

### Translation

| Arabic Transliteration | English     |
| ---------------------- | ----------- |
| `mgs`                  | Scissors ✂️ |
| `hajara`               | Rock 🪨     |
| `wargeh`               | Paper 📄    |
